# HabitFlow 🌿
### Build Better Habits. Build a Better You.

HabitFlow is a Flutter-based habit tracking application designed to help users build consistency, manage daily routines, and monitor personal progress through a structured and intuitive interface.

The application organizes daily activities into four key areas: Study, Spiritual, Prayer, and Health & Fitness.

## ✨ Features

### 📚 Study
- Track daily study habits.
- Monitor task completion.
- Build consistent study routines.

### 🌿 Spiritual
- Track Quran Tilawat.
- Manage Morning Adhkar.
- Manage Evening Adhkar.
- Maintain spiritual routines.

### 🕌 Prayer
- Track the five daily Salah.
- Monitor daily prayer completion.
- Maintain consistency in prayer routines.

### 💪 Health & Fitness
- Track daily exercise and walking.
- Monitor water intake.
- Maintain healthy eating habits.
- Track sleep routines.

### 📊 Progress Tracking
- Daily habit completion tracking.
- Habit streak monitoring.
- Calendar-based habit history.
- Analytics and progress overview.

### 🔔 Reminders
- Set daily reminders for habits.
- Receive scheduled notifications.
- Customize reminder times.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Firebase project configuration

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Hasibur02/HabitFlow.git
```

**2. Navigate to the project directory**

```bash
cd HabitFlow
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Configure Firebase**

Configure your own Firebase project and generate the required FlutterFire configuration.

**5. Run the application**

```bash
flutter run
```
